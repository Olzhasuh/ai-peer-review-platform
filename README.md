## Project Description

This diploma project aims to develop a web-based platform that combines structured peer review with machine learning-assisted feedback for language learners.

The platform will allow students to submit writing assignments, review classmates' work, receive structured feedback, and improve their writing skills using machine learning recommendations.

## Planned Technology Stack

Frontend: React, TypeScript

Backend: Python, FastAPI

Database: PostgreSQL

Machine Learning: Python, scikit-learn / PyTorch (to be finalized)

Version Control: GitHub

Project Management: YouTrack

## Planned Features

1. User registration and authentication
2. Student and teacher dashboards
3. Writing assignment submission
4. Structured peer review
5. Machine learning-assisted writing feedback
6. Feedback history and revision tracking
7. Teacher monitoring
